# Project 01 — Static Website on AWS EC2

## What I Built
Deployed a personal portfolio website on AWS EC2
using Nginx as the web server.

## Architecture
Internet → IGW → EC2 (Public Subnet) → Nginx → index.html

## Steps I Followed
1. Launched EC2 t2.micro (Ubuntu)
2. Configured Security Groups (Port 22, 80)
3. SSH into server
4. Installed and configured Nginx
5. Uploaded HTML file
6. Website went live on public IP

## What I Learned
- How EC2 instances work
- Security Groups — port level access control
- How Nginx serves static files
- SSH connection to remote server
- Linux basic commands on real server

 ## Tech Used
- AWS EC2
- Ubuntu 
- Nginx
- HTML/CSS
